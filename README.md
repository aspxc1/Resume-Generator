# Jake's Resume Builder

A private browser app that formats **your own writing** for tech and engineering resumes using [Jake Gutierrez's Resume Template](https://github.com/jakegut/resume).

Includes live preview, PDF printing, editable LaTeX export, custom sections, local draft saving, and JSON backups. All resume content is written by you and stays in your browser.

## Run

Requires Node.js 22.12+.

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Development

`npm test` runs unit tests, `npm run test:e2e` runs browser tests, and `npm run build` creates the production build.
